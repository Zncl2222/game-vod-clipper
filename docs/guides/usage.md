# 操作指南

[回到繁體中文 README](../../README.zh-TW.md)

## 匯入影片

在「匯入」選擇本機影片或 YouTube 網址。本機匯入會列出後端原片與成品資料夾內的檔案；先把錄影放入 `downloads/` 或自訂原片資料夾。瀏覽器不會將原始檔上傳到後端。

YouTube 支援已結束、可下載的公開或不公開影片；不支援進行中的直播與需要登入才能下載的影片。
畫質預設為最高可用，可設定解析度上限。新匯入專案直接播放原片，時間軸縮圖在背景建立；舊專案可繼續使用既有預覽。

從自己的頻道挑選或批次匯入直播，請見 [YouTube 工作流程](youtube.md)。

## AI 連線與搜尋

手動剪輯可直接使用。AI 聊天與畫面分析共用後端環境中的 Codex CLI 連線。
在「帳號設定」完成登入，確認帳號與計費模式，再選擇模型。容器使用裝置碼登入，詳見 [部署指南](deployment.md)。
「測試 AI 文字回應」會實際送出一則測試訊息，不會處理影片。

選取影片後，可按「一鍵搜尋成功挑戰」，或在 AI 對話指定搜尋範圍。模型與推理設定以介面當下提供的選項為準。
搜尋會逐步發布候選與證據；停止或尚未完成的分析仍可能留下待核對候選。遇到中斷時，可依工作狀態使用「接續細查」重用既有觀察；來源改變會使舊檢查點失效。

AI 對話可處理一般問題，也能接受「跳到 1 分 30 秒」、「把勝利後收尾改成 8 秒」等編輯要求。
搜尋與匯出有各自的任務狀態，停止文字回應不等於取消已排隊的搜尋，請使用任務卡的取消操作。

畫面分析會將抽樣影像傳給模型服務，原始影片留在本機。AI 判斷可能不完整，候選仍需預覽核對。
「用量與額度」顯示本機記錄的 token 與帳號回報的額度；分析期間的額度差值只是估計，不能直接以 token 換算訂閱百分比。

## 核對與調整候選

1. 選取候選，使用預覽及前後段切換查看原片。
2. 確認起點是成功挑戰的開始，沒有含入前次死亡、讀取、重生或跑圖。
3. 確認勝利有明確畫面證據，不只依賴血條消失或轉場。
4. 調整開始與勝利時間，保留勝利後 5–10 秒，再檢查整段連續性。

「待核對／保留／排除」用於整理候選，不代表已完成驗證，也不是匯出門檻。
「請 AI 複判這段」會針對目前候選區間追加檢查；回覆不會自動覆寫正在編輯的範圍。

候選的手動編輯會保留在目前瀏覽器；「儲存區間」將修正保存到專案，與原始 AI 判斷分開。
有效區間可直接匯出並自動保存，不需要勾選額外確認框。未知的勝利時刻應先定位，再匯出。

## 匯出與成品

輸入片名並匯出 MP4，進度與失敗原因可在工作區查看。輸出取自原片，保留來源解析度與幀率；偏好設定可選擇匯出畫質。

成品預設位於：

```text
clips/web/<project-id>/<job-id>.mp4
```

「檔案儲存位置」會顯示實際路徑。「下載 MP4」會透過瀏覽器另存一份。
在「成品」選取片段，可回到原片區間修改並「另存新成品」；原片與成品草稿分開保存，既有成品不會被覆寫。
只有完成且通過輸出驗證的成品可由介面上傳 YouTube，原始 VOD 不可上傳。

## 儲存位置與清理

「偏好設定 → 儲存位置」可更改原片、成品及暫存資料夾。更改只影響新檔案，舊專案仍使用原路徑。
資料庫、YouTube 登入與遊戲設定仍位於後端工作區的 `runs/web/`；工作區由 `GAME_VOD_ROOT` 決定，未設定時使用啟動目錄。

「本地影片用量」可查看與重新計算容量，儲存管理則提供清理選項。
不要直接刪除整個 `runs/` 當作清除快取，裡面包含專案狀態與帳號資料。
容器內的儲存位置必須是已掛載的容器路徑，詳見 [部署指南](deployment.md)。

## 常見問題

| 狀況 | 檢查方式 |
| --- | --- |
| 本機影片沒有出現在清單 | 確認影片在後端的來源資料夾，並重新整理匯入清單；Docker 檢查掛載路徑 |
| YouTube 提示缺少 JavaScript runtime | 執行 `uv run game-vod-clipper check`，確認後端 PATH 有 Deno 或 Node.js |
| YouTube 下載 HTTP 403 | 確認影片已結束且可公開下載，檢查 yt-dlp 與 runtime；仍失敗可使用本機錄影 |
| 已登入但 AI 不能回應 | 查看介面回報的權限、額度或連線錯誤；登入成功不代表模型呼叫成功 |
| 頁面沒有顯示最新前端 | 重新執行 `npm --prefix web run build`；Docker 則重建映像 |
| 重新啟動後資料看似消失 | 檢查啟動目錄、`GAME_VOD_ROOT`、Compose 專案名稱及掛載位置 |
