# YouTube 工作流程

[回到繁體中文 README](../../README.zh-TW.md) · [操作指南](usage.md)

流程為：**連接頻道 → 匯入直播 → 核對片段 → 匯出 → 確認上傳**。
只需要貼網址匯入時，不必先連接自己的頻道。

## 連接自己的頻道

1. 在 Google Cloud 專案啟用 YouTube Data API v3，設定 OAuth 同意畫面；個人測試時加入自己的測試帳號。
2. 建立 OAuth 用戶端並下載 JSON。以 `localhost` 或 `127.0.0.1` 開啟工作區時可用桌面應用程式用戶端；遠端 HTTPS 需網頁應用程式用戶端，並登記介面顯示的完整 `/api/youtube/callback` 重新導向 URI。
3. 在「我的 YouTube」選擇 JSON，按「使用 Google 連接」，選擇自己的頻道並授權。
4. 登入視窗與工作區需使用相同瀏覽器與主機名稱，登入途中不要切換 `localhost` 和 `127.0.0.1`。

應用程式使用 `youtube.readonly` 讀取資料、`youtube.upload` 上傳成品。選用播放清單功能時，另請求 `youtube.force-ssl`。
OAuth 設定與權杖存於後端 `runs/web/youtube/`，受本機檔案權限保護；備份時應一起保存並保持私密。

授權過期可重新連接。登入成功但讀不到直播時，先確認連接的頻道正確、已啟用直播，以及專案 API 與權限設定；依介面錯誤提示處理後重新整理。

## 匯入直播

清單提供已結束的自有直播，支援搜尋已載入項目與分頁。下載支援公開及不公開且可取得的存檔；私人影片請改用本機錄影。
OAuth 用於頻道資料與上傳，不會將帳號權杖交給 yt-dlp 下載原片。

- 「保留畫質」預設最高可用，也可選擇 2160p、1440p、1080p、720p 或 480p 上限；不會放大低解析度來源。
- 可選擇「匯入後自動找片段」與分析模型；請先完成 AI 連線。
- 單部按「匯入直播」；多部勾選後按「匯入所選」。重複提交同一影片會沿用匯入紀錄。
- 新匯入影片直接播放原片，時間軸縮圖在背景建立，不必先產生整部低解析度預覽。舊專案可沿用預覽。
- 已匯入來源不會因後續更改畫質而重新下載；要換更高畫質，可使用網址重新建立專案。

「匯入佇列」會保留工作與各自的畫質設定，提供等待、下載、影音合併及後續處理狀態。
關閉對話框或瀏覽器不會停止後端工作。後端重啟會恢復等待中的項目；被中斷的工作依介面提示重試。

可選擇啟用新直播追蹤，讓後端運作期間匯入新完成的直播。此功能預設關閉，啟用時請確認畫質與 AI 模型設定。

## 匯出與上傳

先依 [操作指南](usage.md) 核對成功挑戰與勝利後 5–10 秒，再匯出 MP4。
在「成品」按「上傳 YouTube」，檢查標題、說明、目標頻道、觀看權限與觀眾設定後確認。
上傳預設為私人，只有完成且通過輸出驗證的成品可上傳，不能上傳原始 VOD。

上傳狀態保存在本機，支援進度、暫停與接續。若工作階段過期，先確認 YouTube Studio 是否已有影片，再依介面明確重啟，避免重複上傳。

「加入播放清單」為選填，首次使用須額外授權。加入播放清單失敗可獨立重試，不必重新上傳影片。
YouTube 端的處理時間、API 配額與應用程式審核限制仍會影響結果，以服務回應及介面提示為準。
